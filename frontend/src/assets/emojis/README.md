# Animated Emoji Assets

Drop animated WEBP assets in this folder using codepoint-based filenames.

Examples:

- `1f600.webp` for `😀`
- `1f62d.webp` for `😭`
- `1f525.webp` for `🔥`
- `2764-fe0f.webp` for `❤️`

The renderer resolves assets lazily at runtime, so you can add more files without changing the component code.
